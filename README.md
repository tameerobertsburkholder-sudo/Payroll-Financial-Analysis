# Payroll & Financial Analysis

## Project Overview
This business analytics portfolio project explores payroll operations, financial reconciliation, data validation, and management reporting using simulated employee payroll data.

## Project Objectives
- Analyze monthly payroll expenditures.
- Identify payroll discrepancies and reporting errors.
- Compare compensation expenses across departments.
- Evaluate overtime costs and payroll trends.
- Develop financial dashboards and management reports.
- Demonstrate payroll reconciliation and data validation techniques.

## Tools and Technologies
- Microsoft Excel
- SQL
- Microsoft Power BI

## Professional Background
This project draws upon my professional experience in international payroll administration, financial operations, audit coordination, and my ongoing Business Analytics studies at Ensign College.

## Data Privacy
All employee and financial records used in this project will be fictional and created exclusively for analytical demonstration.
